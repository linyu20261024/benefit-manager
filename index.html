CSV 模板

下载后用 Excel/WPS 编辑，每行填写一项权益；请保留首行字段名。模板只包含权益数据，不包含会员体系和平台库。保存为 CSV UTF-8 后再导入。有效期类型可填写 date（指定日期）、long（长期有效）、unknown（待确认）；状态可填写待使用、已使用、已过期、已失效。

导入 CSV

适合从 Excel、表格或其他系统导入权益列表。只导入 CSV 支持的权益字段，采用“追加”方式，不覆盖现有权益；会员体系和平台库不包含在 CSV 中。

恢复 JSON 备份

适合恢复本工具导出的完整备份，包含权益、平台会员和自定义平台。恢复会替换当前数据，恢复前建议先导出备份。旧版本 JSON 也会尽量兼容。

导出 JSON 备份

将权益、会员记录和平台库保存为一个文件，建议在更新网页或更换浏览器前备份。
